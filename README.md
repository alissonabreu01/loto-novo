# LotoFácil - Sistema de Análise Estatística

Sistema de análise e geração de apostas da Lotofácil baseado em padrões estatísticos históricos.

## Funcionalidades

- **Dashboard**: estatísticas históricas (frequência, ímpares/pares, moldura × miolo, repetição, pares e trincas mais frequentes)
- **Gerador**: geração de jogos com filtros baseados no perfil histórico e score de aderência
- **Verificador**: compara um jogo contra todo o histórico
- **Histórico**: tabela dos últimos concursos
- **Janela Móvel**: análise de convergência estatística com métricas de Pearson, RMSE, Jensen-Shannon, boxplot e heatmap

## Como executar

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`

## Aviso

Este sistema é exclusivamente uma ferramenta de análise estatística e entretenimento. Os jogos gerados não constituem método de previsão e não alteram as probabilidades fundamentais do sorteio.
